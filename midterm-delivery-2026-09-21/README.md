# 中期开发交付包

本文件夹是给中期报告和汇报 PPT 制作者的单独材料包。材料以 2026-09-21 的可运行版本为准，截图来自隔离运行和合成会议纪要，不包含 API Key、私人纪要或真实第三方任务数据。

## 文件说明

- `MIDTERM_REPORT.md`：中期报告技术正文，可按学校模板调整。
- `MIDTERM_PROCESS_RETROSPECTIVE.html`：中期制作过程复盘，区分已修正问题、持续挑战和不能越界的验收结论，可直接在浏览器中打开。
- `PPT_MATERIALS.md`：汇报短文案、9 页叙事、对话能力矩阵和后期目标。
- `FUNCTION_GROUPS.md`：按功能场景组织截图，避免把同一功能的状态变化误当成多个亮点。
- `TEST_EVIDENCE.md`：验收记录、测试边界和证据口径。
- `screenshots/`：按功能类型归类的图片副本。

## 使用边界

中期使用 `Local Task Hub` 作为受控演示连接器，不要把 `LTH-*` ID 写成飞书、Trello 或 Notion 的真实任务。后期目标只保留真实任务平台接入和基于人工标注会议数据的效果评测。47 项自动化测试证明工程边界，不代表真实会议准确率。

截图主线优先展示三项开题问题：AI 提出优先级并由人工审核、成员别称归一、人员与任务关系不明确时主动澄清。每个功能组选择“输入/处理中/结果”中的必要图片即可，附录图片用于答辩追问，不要把所有图片塞进 PPT 正文。

姓名示例均为虚构测试名：张三、李四、王五、赵六；别称示例为“老张、张哥、小张都指张三”。
